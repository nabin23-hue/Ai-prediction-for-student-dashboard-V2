How to Use the System

Simple tutorial for admin, teacher, and student users

Login Admin Teacher Privacy

Admin Steps

  1. Login using admin / 123.
  2. View all students, teachers, risk levels, and system summary cards.
  3. Add, edit, delete, view, and download student reports.

Teacher Steps

  1. Login using teacher / 123.
  2. View class summary, risk distribution, and student monitoring table.
  3. Filter high-risk students and open the student detail page.
  4. Use teacher intervention actions to support students early.

Student Steps

  1. Login using laxman / 123, nabin / 123, or nishan / 123.
  2. View productivity score, risk level, expected grade, and pass probability.
  3. Check streaks, goals, badges, weekly chart, and AI recommendations.
  4. Update details and click Predict Performance.
