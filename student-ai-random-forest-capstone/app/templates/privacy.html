Privacy Notice

Student data in this prototype is used only for academic support, early intervention, and performance improvement.

Ethical AI Use

Prediction results should not be used to punish students. They should be used to provide support, reminders, and teacher guidance.

Security Considerations

  • Admin can manage users and records.
  • Teachers can monitor class performance and support at-risk students.
  • Students should only access their own academic progress.
  • Real passwords should be hashed in a production system.
  • Real private student data should not be used in this demo.
